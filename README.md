# Max Mobbiles - Repair Shop Website

A premium, dynamic web application for Max Mobbiles, a mobile repair shop in Vanasthalipuram.

## Tech Stack
- React
- Vite
- TailwindCSS (if applicable, via vanilla CSS patterns)
- Phosphor Icons

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
